# VoiceNote Core (`voicenote-core`)

`voicenote-core` is the high-performance, memory-safe native Rust library that powers VoiceNote's offline speech-to-text, voice activity detection, tone rewriting, and cryptographic integrity verification on macOS, iOS, and Android.

---

## 1. Architecture & Crate Layout

The crate is located under `rust/voicenote-core` and compiles to a static library (`libvoicenote_core.a`) and dynamic library (`libvoicenote_core.so` / `cdylib`) with a C-ABI interface generated by `cbindgen`. The C-ABI is exposed to TypeScript via a React Native Nitro Modules JSI shim (`RustCoreHybridObject`).

### Crate Structure

```
rust/voicenote-core/
├── Cargo.toml
├── cbindgen.toml
├── build.rs                     # cbindgen execution & iOS CoreML build alert
├── voicenote_core.h             # C header generated at build time
└── src/
    ├── lib.rs                   # C-ABI extern "C" entry points, FFI types & allocators
    ├── android_jni.rs           # Android JNI bindings for Kotlin bridge via cargo-ndk
    ├── errors.rs                # C-compatible error taxonomy (VnErrorCode 1:1 with MlErrorCode)
    ├── model_coordinator.rs     # Mutual exclusion (< 500 MB RAM budget) & 60s idle auto-unload
    ├── audio/
    │   ├── mod.rs
    │   ├── buffer.rs            # AudioBuffer with RAII Drop ephemerality for safe file cleanup
    │   ├── silence_trim.rs      # PCM RMS speech boundary detection & 200 ms phoneme padding
    │   └── wav.rs               # 44-byte RIFF WAV header serialization
    ├── vad/
    │   ├── mod.rs
    │   ├── silero.rs            # Silero VAD V4 ONNX engine via tract-onnx
    │   ├── presets.rs           # Sensitivity presets (Low, Medium, High)
    │   └── gate.rs              # Debounced state machine (idle -> speech -> silence -> auto-stop)
    ├── asr/
    │   ├── mod.rs
    │   ├── whisper.rs           # Whisper ASR engine wrapping whisper-rs (whisper.cpp)

    ├── slm/
    │   ├── mod.rs
    │   ├── llama.rs             # On-device GGUF SLM engine (<500MB RAM budget, header validation & structured rewriting)
    │   └── validator.rs         # Hallucination guard (entity preservation regex & length bounds)
    └── crypto/
        ├── mod.rs
        └── sha256.rs            # Streaming SHA-256 verifier using ring v0.17
```

## 2. Core Subsystems

### 2.1 Audio Subsystem (`src/audio/`)
- **`AudioBuffer`**: Manages 16 kHz / 16-bit / mono linear PCM buffers. Implements `Drop` RAII ephemerality: any temporary audio file written to disk is strictly deleted when the buffer falls out of scope or is aborted mid-flight.
- **`silence_trim.rs`**: Computes frame RMS energy, discards leading and trailing silence, and guarantees 200 ms of padding to prevent clipping boundary phonemes. If no speech is found, returns `has_speech = false` to short-circuit expensive downstream ML operations.
- **`wav.rs`**: Serializes raw PCM into canonical 44-byte RIFF WAVE files for consumption by model decoders.

### 2.2 Voice Activity Detection (`src/vad/`)
- **`silero.rs`**: Runs the Silero VAD V4 ONNX model on-device via `tract-onnx` without external runtime dependencies or phase distortion.
- **`presets.rs`**: Maps sensitivity levels (`Low`, `Medium`, `High`) to speech probability thresholds (0.6, 0.5, 0.35).
- **`gate.rs`**: Implements a debounced state machine (`idle` → `speech` → `silence`). Triggers `auto-stop` when silence continues past the configured window (`autoStopSilenceMs`, default 1500 ms).

### 2.3 ASR Engine (`src/asr/`)
- **`whisper.rs`**: Asynchronous transcription engine backed by `whisper-rs` (whisper.cpp) with Metal GPU acceleration on Apple Silicon.
- **`segmenter.rs`**: Slices long audio (>27 s) at detected silence points, transcribing slices independently with adaptive timeouts (`3 × audio duration + 15 s`, clamped to [30 s, 120 s]) and merging the results.
- **Bilingual Strategy**: Audio shorter than 1.5 s defaults to English. Longer audio uses code-switching Hinglish prompts to preserve English and Devanagari scripts appropriately.

### 2.4 SLM Tone Rewriting & Hallucination Guard (`src/slm/`)
- **`llama.rs`**: On-device GGUF SLM engine. `LlamaEngine` validates GGUF container headers and memory coordination (< 500 MB RAM budget), and performs structured tone rewriting validated by the Rust hallucination guard (`validate_preservation`). Standalone zero-dependency library with no external third-party cmake llama.cpp binary bundled.
- **`validator.rs`**: Rust hallucination guard:
  - Extracts critical entities (numbers, currencies, percentages, dates/times, capitalized proper nouns) using regex while filtering filler words and sentence starters.
  - Requires all extracted entities to appear in the rewritten text (accounting for time variants like "3pm" ↔ "3:00 PM" and ordinals like "15th" ↔ "15").
  - Enforces length ratio bounds: rewritten length must be between 0.35× and 2.5× of the raw text.

### 2.5 Model Coordinator & Memory Protection (`src/model_coordinator.rs`)
- Enforces strict mutual exclusion between ASR (Whisper) and SLM (Llama) memory allocations:
  - Whisper and Llama are never loaded concurrently, keeping peak RAM well under the **< 500 MB** budget.
  - An idle timer automatically unloads inactive models after 60 seconds to restore baseline RAM.

### 2.6 Cryptographic Verification (`src/crypto/`)
- **`sha256.rs`**: Streaming SHA-256 verifier powered by `ring = "0.17"`. Verifies downloaded model weights chunk-by-chunk directly from disk with minimal memory overhead before registration.

### 2.8 Android JNI Subsystem (`src/android_jni.rs`)
- Implements JNI `extern "system"` entry points exposed to Kotlin via `VoiceNoteCoreJni`:
  - `Java_com_voicenote_core_VoiceNoteCoreJni_trimSilenceWav`: Audio silence trimming and RIFF WAV serialization.
  - `Java_com_voicenote_core_VoiceNoteCoreJni_verifyFileChecksum`: Zero-copy SHA-256 model weight integrity verification.
  - `Java_com_voicenote_core_VoiceNoteCoreJni_transcribeAudio`: On-device Whisper transcription returning structured `VoiceNoteAsrResult`.
  - `Java_com_voicenote_core_VoiceNoteCoreJni_getCoreVersion`: Crate semantic version string (`"1.0.0"`).

### 2.9 Error Taxonomy (`src/errors.rs`)
- Defines `VnErrorCode` mapping 1:1 to TypeScript `MlErrorCode`:
  - `101`: `ASR_EMPTY_OUTPUT`
  - `102`: `ASR_TIMEOUT`
  - `103`: `ASR_MODEL_MISSING`
  - `201`: `SLM_TIMEOUT`
  - `202`: `SLM_HALLUCINATION_SUSPECTED`
  - `301`: `MODEL_CHECKSUM_FAILED`
  - `302`: `STORAGE_FULL`
  - `401`: `AUDIO_RECORD_FAILED`
  - `999`: `UNKNOWN`

## 3. Cross-Compilation Workflows

Build scripts are located in `scripts/`:

### 3.1 macOS Universal Build (Apple Silicon & Intel)
Compiles `libvoicenote_core.a` for dual targets (`aarch64-apple-darwin` and `x86_64-apple-darwin`), combines them into a universal fat static library via Apple `lipo`, and copies the archive and generated C header to `macos/build/rust/`:
```bash
bash scripts/build-macos.sh
# Alternatively used automatically by: npm run build:macos:dmg
```
Artifacts generated:
- `macos/build/rust/libvoicenote_core.a` (Universal `arm64` + `x86_64`)
- `macos/build/rust/voicenote_core.h`

### 3.2 iOS (Device + Simulator XCFramework)
Compiles targets `aarch64-apple-ios` and `aarch64-apple-ios-sim`, and bundles them into an Apple `XCFramework`:
```bash
bash scripts/build-ios.sh
```
Artifacts generated:
- `ios/RustCore.xcframework`

> **Note on CoreML**: `build.rs` checks if `--features coreml` is enabled when building for iOS. If absent, a compiler alert notifies the developer that whisper-rs will fall back to CPU NEON SIMD vectorization.

### 3.3 Android JNI Libraries (`cargo-ndk`)
Uses `cargo-ndk` to cross-compile for Android (`aarch64-linux-android`, API level 29) and outputs the shared library to the Android project's `jniLibs` directory:
```bash
bash scripts/build-android.sh
# Alternatively used automatically by: npm run build:android:release
```
Artifacts generated:
- `android/app/src/main/jniLibs/arm64-v8a/libvoicenote_core.so`

*(If `cargo-ndk` or `ANDROID_NDK_HOME` is not detected in the environment, the script outputs a graceful notice with remediation commands and skips compilation).*

## 4. Running Tests

Unit and integration tests run entirely offline with synthetic fixtures:

```bash
cargo test --manifest-path rust/Cargo.toml
```

### Test Suites Included (68 Tests)
- `tests/audio_buffer_test.rs`: Zero-length PCM safety, RAII `Drop` temporary file deletion, sample normalization.
- `tests/silence_trim_test.rs`: Pure silence detection, speech padding preservation, boundary clamping.
- `tests/wav_test.rs`: 44-byte RIFF header validation, C-ABI `vn_audio_trim_and_save_wav`.
- `tests/vad_test.rs`: Silero V4 ONNX model loading, sensitivity thresholds, recurrent state resets, `vn_vad_eval_pcm_chunk`.
- `tests/asr_segmenter_test.rs`: Long audio segmentation, dominant language detection, Hinglish heuristics.
- `tests/whisper_test.rs`: Missing model handling, empty input guards, C-ABI `vn_asr_transcribe`.
- `tests/llama_test.rs`: GGUF loading, timeout enforcement, `ModelCoordinator` mutual exclusion and 60s idle auto-unload, C-ABI `vn_slm_generate`.
- `tests/hallucination_guard_test.rs`: Entity preservation (currencies, dates, ordinals, time variants), length bounds.
- `tests/crypto_test.rs`: Streaming SHA-256 verification via `ring`, C-ABI `vn_crypto_verify_sha256`.
- `tests/scaffold_test.rs`: Version string alloc/free, error code enum integer stability.

## 5. Non-Negotiable Safety & Privacy Invariants

1. **Zero Cloud Inference**: All Whisper, Silero VAD, and LLaMA operations execute strictly on-device.
2. **Audio Ephemerality**: Temporary audio files are deleted immediately after transcription via `AudioBuffer::drop()`.
3. **Zero Telemetry**: No logging, crash reporting, or network calls are made from the native core.
4. **RAM Budget < 500 MB**: `ModelCoordinator` guarantees Whisper and LLaMA never co-exist in memory.
