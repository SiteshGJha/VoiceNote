# VoiceNote Rust Core — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace VoiceNote's simulated native layer with a production Rust static library (`voicenote-core`) that delivers real on-device audio processing, VAD, ASR, and SLM inference on macOS, iOS, and Android, while keeping the React Native/TypeScript UI and all existing TS types untouched.

**Architecture:** A Rust crate (`rust/voicenote-core`) exposes `extern "C"` functions; `cbindgen` generates a C header; a C++ `HybridObject` shim (Nitro Modules) makes those functions callable from TypeScript via JSI. Phase 0 proves the toolchain and bridge on macOS, iOS, and Android; Phases 1–5 implement one subsystem per phase; each phase ends with existing 74+ Jest tests passing and a new Rust `cargo test` suite green.

**Tech Stack:**
- Rust 1.82+ (edition 2021) · `tokio` v1 · `ring` v0.17 · `thiserror` v1
- VAD: `silero-vad-rs` (Silero V4 ONNX via `tract-onnx`)
- ASR: `whisper-rs` (0.12+) → whisper.cpp (with Metal and optional compile-time CoreML)
- SLM: `llama-cpp-4` → llama.cpp (GGUF K-quants)
- Bridge: `cbindgen` + Nitro `HybridObject` C++ shim (`src/native/rustCore/`)
- Platforms: macOS (`aarch64-apple-darwin`), iOS (`aarch64-apple-ios`), Android (`aarch64-linux-android` via `cargo-ndk`)

## Global Constraints

- React Native 0.76.9, `react-native-nitro-modules` 0.18.0, `react-native-macos` 0.76.12 — no version bumps
- TypeScript strict mode — zero `any`, zero `@ts-ignore`
- Existing `AsrResult`, `SlmResult`, `PipelineResult` types in `src/ml/types.ts` are frozen — Rust layer outputs must match these discriminated unions
- Error codes in `src/ml/errors.ts` are frozen — `rust/voicenote-core/src/errors.rs` maps to them 1:1 via `thiserror`
- Audio: 16 kHz / 16-bit / mono PCM always. No stereo, no 44.1 kHz output from Rust
- Temp audio files deleted inside Rust immediately after ASR returns via `Drop` on `AudioBuffer`
- Peak memory budget: < 500 MB (Whisper and SLM are mutually exclusive in memory via model coordinator)
- Rust inference runs on a `tokio` worker thread, never blocking the JSI UI thread
- `npm run audit:privacy` must produce zero violations after every phase
- `npm run typecheck` must produce zero errors after every phase
- All 74+ existing Jest tests must pass after every phase (`npm test`)

## Review Focus

These are the 5 edge-case input classes most likely to fail silently without explicit tests:

1. **Zero-length PCM handed to Rust** — must return `ASR_EMPTY_OUTPUT`, not panic or divide by zero; pinned to test in Task 1.1 Step 1 and Task 3.3 Step 1.
2. **Audio capture cancelled or interrupted mid-recording** — `AudioBuffer` `Drop` must guarantee temp WAV file deletion even when tasks abort; pinned to test in Task 1.1 Step 1 and Task 1.4 Step 2.
3. **Whisper CoreML flag absent at compile time on Apple targets** — build script must emit a loud compiler warning to alert developers of CPU-only fallback; pinned to verification in Task 3.1 Step 5.
4. **Corrupt, truncated, or non-existent GGUF model file** — `llama-cpp-4` load must fail safely with `VnError::AsrModelMissing` or `VnError::ModelChecksumFailed`, never segfaulting; pinned to test in Task 4.1 Step 1.
5. **SLM rewrite drops numbers, dates, or proper nouns** — hallucination guard must reject the rewrite and trigger fallback to raw transcript; pinned to test in Task 4.2 Step 1.

  pub struct AudioBuffer {
      pcm: Vec<i16>,
      sample_rate: u32,
      temp_path: Option<std::path::PathBuf>,

  impl Drop for AudioBuffer {
      fn drop(&mut self) {
          if let Some(ref p) = self.temp_path {
              let _ = std::fs::remove_file(p);
          }
      }
  }
  impl AudioBuffer {
      pub fn from_pcm(pcm: Vec<i16>, temp_path: Option<std::path::PathBuf>) -> Self;
